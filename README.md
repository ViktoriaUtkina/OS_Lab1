# Лабораторная работа №1

## Что делает

Скрипт `log_archiver.sh`:

1. Принимает три аргумента: путь к папке логов, порог в процентах (N), количество файлов для архивации (M).
2. Считает, какой процент от файловой системы занимает указанная папка.
3. Если процент превышает порог N - находит M самых старых файлов (по времени последней модификации) и архивирует их в `tar.gz`.
4. Архив сохраняется в `/backup` с именем вида `backup_YYYYMMDD_HHMMSS.tar.gz`.

### Запуск тестов

Ожидаемый результат: `PASS=5 FAIL=0`.

## Тестовые кейсы

| № | Что проверяется                                    |
|---|----------------------------------------------------|
| 1 | Порог не превышен - архив НЕ создаётся             |
| 2 | Порог превышен - архив создаётся с ровно M файлами |
| 3 | В архив попадают именно САМЫЕ СТАРЫЕ файлы         |
| 4 | Обработка неверного количества аргументов          |
| 5 | Обработка несуществующей папки                     |

## Технические детали

- Расчёт процента: `du -sk` (размер папки) / `df -k --output=size` (размер ФС).
- Поиск старых файлов: `find -printf '%T@\t%p\n' | sort -n | head -n M`.
- Безопасная передача имён с пробелами: `tr '\n' '\0'` + `tar --null -T -`.
- Архивация: `tar -czf` (формат tar+gzip).
