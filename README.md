# Лабораторная работа №1

## Что делает

Скрипт `log_archiver.sh`:

1. Принимает три аргумента: путь к папке логов, порог в процентах (N), количество файлов для архивации (M).
2. Считает, какой процент от файловой системы занимает указанная папка.
3. Если процент превышает порог N - находит M самых старых файлов (по времени последней модификации) и архивирует их в `tar.gz`.
4. Архив сохраняется в `/backup` с именем вида `backup_YYYYMMDD_HHMMSS.tar.gz`.

## Как запустить

### Подготовка: виртуальный диск `/log` на 10 МБ

Процент считается как (размер папки) / (размер файловой системы). Если папка лежит на большом диске, порог в 70% практически недостижим. Поэтому создаём отдельный виртуальный диск на 10 МБ и монтируем его как `/log`.

```bash
sudo mkdir -p /log /backup
sudo dd if=/dev/zero of=/var/log_disk.img bs=1M count=10
sudo mkfs.ext4 /var/log_disk.img
sudo mount -o loop /var/log_disk.img /log
sudo chmod 777 /log /backup
